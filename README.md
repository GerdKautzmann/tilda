# The Legend of Tilda

A small top-down 2D adventure in C++17 with SDL2. It is a parody: Tilda has to find and rescue
her little brother Tunk, who has been locked in a cage by King Slime. Free him and go on ... 

## How to install, compile, run (Linux)

# Users install g++ and libsdl2-dev, run make, then ./tilda
sudo apt-get install g++ libsdl2-dev
make run
