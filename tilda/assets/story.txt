# ============================================================================================
#  story.txt - every dialog, quest objective and story trigger of "The Legend of Tilda".
#  Edit it with any text editor; press F5 in the game to reload it (this restarts the game).
#
#  STRUCTURE
#    talk NAME         what a person says when Tilda talks (E) to them. NAME is a name from npcs.txt
#                      (elder brothilda pip tunk raylin reg sheep dancer albino baron barkeeper maid knight
#                      servant), or: chicken, sign, tunkfollower (Tunk after he joined)
#    examine NAME      what Tilda finds when she examines (X) something in front of her:
#                      books, bed, bar, table
#    objective         the line on the Status page (the first matching block wins)
#    trigger           something that starts by itself as soon as its conditions are true (once)
#
#  Inside a section:
#    when COND COND ...   starts a block. The FIRST block whose conditions are all true is used.
#    else                 a block without conditions (put it last)
#    say NAME | text      one speech box. NAME "$" = the person talked to, empty = narrator text
#    ---                  starts the next conversation of the same block: successive talks cycle
#                         through them (conversation 1, 2, 3, 1, 2, ...)
#    do COMMAND ARGS      runs when the conversation ends (see below)
#    text ...             (objective blocks) the objective
#
#  CONDITIONS   var=N  var!=N  var<N  var>N  var<=N  var>=N   (no spaces; several are all required)
#    quest        the main quest step (0..10)           kills      slimes beaten so far
#    coins        weapon   0 none, 1 spoon, 2 spork, 3 sword
#    sheepq       Reg's side quest 0/1/2               sheepfound sheep that are home (0..5)
#    seenrealm    1 once Tilda left the cave           key        1 if Tilda has the cave key
#    clues        how many clue_... flags are set      px, py     Tilda's position in tiles
#    anything else is a flag of your own (0 until set), for example  book1=1
#  TEXT can contain {kills}, {sheepfound}, {swordprice}, {clues}, ... (a variable in curly braces)
#
#  COMMANDS (do ...)
#    set quest 7        set sheepq 1        set NAME 1 (your own flag)       add coins 25
#    giveweapon 2       heal                 spawnking                        givekey
#    spawndragon        (re)creates the dragon in its lair (once quest>=9) or Dina (once dina_found=1)
#    tunkjoin           shop brothilda|reg   sheephome (the sheep talked to)  sfx jingle|coin|heal|hurt
#    toast TEXT         fairy TEXT (Nagi says it)
# ============================================================================================

talk reg
when sheepq=0
say $ | Well, hello there! Reg's the name, onions are the game.
say $ | My onion stew heals you bit by bit. Rich in layers, just like me.
say $ | But I'm in a pickle. My five sheep ran away. It was probably the smell. Could you find them for me?
say $ | Talk to a sheep and it will trot home. I'll pay you well. Meanwhile, have a look at my stew.
do set sheepq 1
do sfx jingle
do toast Side quest: find Reg's five sheep (0/5)
do shop reg
when sheepq=1 sheepfound>=5
say $ | All five sheep are back in the pen! Baa-rilliant! Here, 25 coins for your trouble.
say $ | Care for some stew while you are here?
do set sheepq 2
do add coins 25
do sfx coin
do toast +25 coins! Side quest complete.
do shop reg
when sheepq=1
say $ | Any sheep yet? {sheepfound} of 5 are back home. They can't have gone far.
do shop reg
else
say $ | Thanks again for the sheep! Hungry?
do shop reg
