# The Legend of Tilda

A small top-down 2D adventure in C++17 with SDL2. It is a parody: Tilda has to find and rescue
her little brother Tunk, who has been locked in a cage by King Slime. Nothing needs to be
downloaded to play it. 

## How to install, compile, run (Linux)

sudo apt-get install g++ libsdl2-dev
make run
